# Vaishnavi Portfolio

## Requirements
- Node.js 18 or higher → https://nodejs.org (download LTS version)
- npm (comes with Node.js automatically)

## Run locally (Command Prompt / Terminal)

Step 1 — open folder in Command Prompt:
  cd path\to\vaishnavi-standalone

Step 2 — install dependencies (only once):
  npm install

Step 3 — run the portfolio:
  npm run dev

Step 4 — open in browser:
  http://localhost:3000

To stop: press Ctrl + C

## Build for deployment (Netlify / Vercel)

  npm run build

Upload the generated `dist/` folder to Netlify Drop or Vercel.

## Replace profile photo
Drop your photo as `public/profile.jpg` and re-run.
